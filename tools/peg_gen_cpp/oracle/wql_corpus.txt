# WQL cross-backend oracle corpus — one query per line, '#' = comment.
#
# Harvested from the single-line deem! bodies in tests/ and examples/, i.e. the
# surface the compiler ACTUALLY parses, plus the numeric-literal shapes that the
# EL oracle's expression-only corpus could never reach. Lines both backends reject
# are kept on purpose: agreeing on a rejection is agreement worth having (run.sh
# fails if EVERY line is rejected, which would make the oracle vacuous).
#
# Add a line here whenever a backend divergence is found. That is what this file
# is for; four divergences shipped before it existed.
