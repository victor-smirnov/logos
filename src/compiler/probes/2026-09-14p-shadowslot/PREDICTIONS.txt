ROUND 2026-09-14p-shadowslot — PREDICTIONS, written after the spec was applied and BEFORE the armed binary existed.
Arms: shslot = whole (sema frame record + moved-state + slot on SDrop + mlir-gen slot resolution)
      shframe = sema half only (same-frame record kept under a hidden key, moved state re-keyed / saved across frames; SDrop names stripped, NO slot)
      shslotmg = carrier half only (slot on SDrop, mlir-gen resolves a drop whose name denotes a different registered binding)
      shmoved = moved-state reset only (same frame: forget the old binding's moves; outer frame: save + restore at pop_scope)
mlir-gen registers a slot at gen_let (SLet) and at gen_function_body params ONLY — pattern binders (extract_payload,
bind_enum_payload, pat_bind, ...), closure params (gen_closure) and for-loop vars are NOT registered, so a drop reaching them
falls back to the name. That is a PARTIAL carrier by construction and the battery below says where it must show.
