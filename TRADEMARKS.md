# Trademark Policy

This document covers use of the **Logos Lang** name and project marks.
It is not a licence — the source code is dual-licensed under
Apache 2.0 / MIT (see [COPYRIGHT](COPYRIGHT)). Marks and code are
governed separately so that the open-source licence can stay
maximally permissive while the project's identity remains
recognisable.

## Marks covered

* **Logos Lang** — the formal wordmark for the language. Always use
  the two-word form ("Logos Lang") in titles, project listings,
  package names, and anywhere the language as a whole is named.
* **logosc** — the canonical compiler binary name.
* **lforge** — the canonical build / package tool name.
* **`.logos`** — the source-file extension.

The bare word "Logos" is **not** claimed by this project. A prior US
registration exists in Class 9 (USPTO serial 99742916, unrelated
party) for the bare wordmark; that's why we use "Logos Lang" as the
formal name. Public references to the language as just "Logos" in
informal speech are fine, but for anything formal — websites,
publications, package metadata, project lists, conference talks —
please use "Logos Lang".

## Permitted uses (no permission needed)

You may use the marks **without prior written permission** for:

* Truthful descriptive use: "written in Logos Lang", "compatible with
  Logos Lang 0.1", "a Logos Lang tutorial".
* Educational, research, and journalistic mention of the project.
* Linking to the project's repository or documentation.
* The unmodified `.logos` extension on source files.
* Naming a library, tool, or package whose primary purpose is to
  interoperate with Logos Lang, provided the name makes it clear
  the project is *yours* (e.g. `myproject-logos`, `logos-vscode`,
  `cool-thing-for-logos-lang`).

When you describe your project, please don't imply official
endorsement or original authorship of Logos Lang itself.

## Uses that require permission

You must contact the project before using the marks for:

* A fork, derivative, or modified distribution that you call "Logos
  Lang" or any close variation thereof. Forks are welcome — please
  name them clearly (e.g. "MyForkLang based on Logos Lang").
* Commercial products that prominently use the marks in branding,
  packaging, or advertising.
* Domain names containing the marks (other than truthful project
  references such as `logos-lang-community.example.org`).
* Merchandise (clothing, stickers, etc.) bearing the marks intended
  for sale.

If you're unsure whether a given use needs permission, ask. The
default answer leans permissive — the goal of this policy is to keep
the *name* unambiguous, not to fence off the community.

## Trademark filing

A formal trademark application for "Logos Lang" is **deferred** until
the project crosses a maturity threshold where the cost / benefit of
filing flips. Until then the marks are claimed via common law
("Logos Lang™" — common-law mark, ™ symbol acceptable in public
references). Once the formal registration completes, this policy
will be updated and the ® symbol becomes appropriate.

## Reporting concerns

Misuse, confusion, or questions about trademark policy: open an
issue on the project's repository or contact the maintainers
through the address listed in [CONTRIBUTING.md](CONTRIBUTING.md).
